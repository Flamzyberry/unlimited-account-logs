# Unlimited Digital Marketplace

A Next.js foundation for a lawful digital-products marketplace.

## Included
- Responsive homepage
- Product cards
- Customer sign-in page
- Customer registration page
- Clean mobile-friendly styling

## Next steps
1. Connect Supabase authentication.
2. Create products, customers and orders tables.
3. Add the customer dashboard and order history.
4. Add an admin dashboard with protected access.
5. Connect a compliant payment provider.
6. Deploy through Vercel.

Do not use this project to sell stolen credentials, compromised accounts, payment-card data, or unauthorized access.
